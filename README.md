# Motor Insurance Risk Assessment

## Project Description

This project investigates how driver age and vehicle age
affect motor insurance claim frequency and expected losses.

The analysis will use real insurance data, probability,
statistics, and Python.

## Project Objectives

- Analyze claim frequency by driver age.
- Analyze claim frequency by vehicle age.
- Compare different insurance risk groups.
- Calculate expected insurance losses.
- Estimate illustrative insurance premiums.
- Visualize and interpret the results.

## Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
